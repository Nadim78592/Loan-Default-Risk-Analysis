# 💳 Loan Default Risk Analysis

> **Exploring borrower and loan characteristics to understand default-risk patterns.**

A focused analytics project designed to examine patterns associated with **loan repayment and default risk** and demonstrate a structured approach to risk-oriented data analysis.

## 🎯 Objective

Identify patterns in borrower and loan data that can help explain differences in default risk and support data-driven lending analysis.

## 🛠️ Analytics Focus

**Data Cleaning · Exploratory Data Analysis · Risk Analysis · KPI Analysis · Data Visualization**

## 🔍 Key Questions

- Which borrower or loan characteristics are associated with higher default risk?
- How does default behavior vary across key customer segments?
- Which variables appear most useful for risk segmentation?
- What patterns should be investigated further before making lending decisions?

## 📊 Project Approach

**Data Preparation → Exploratory Analysis → Risk Segmentation → Pattern Identification → Business Insights**

## 💡 Business Value

The project demonstrates how analytics can be used to move from raw lending records toward **risk segmentation and decision support**, while keeping the distinction between observed patterns and actual credit decisions.
